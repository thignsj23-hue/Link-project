# LINK

Assistente Android com avatar 2D flutuante, conversa por voz e ações locais explícitas.

Licença: [MIT](LICENSE).

- App e instruções de compilação: [LINK-Android/README.md](LINK-Android/README.md)
- Backend FastAPI: [LINK-Backend/README.md](LINK-Backend/README.md)

Tradução e OCR rodam no aparelho. Para conversa inteligente, o app oferece OAuth oficial para solicitar uso elegível do plano ChatGPT, com limites da conta, ou conexão opcional ao backend/API, que pode gerar cobrança separada. O uso do plano não conecta um GPT personalizado nem seu histórico. Consulte o README Android para configurar permissões, conta e serviços.
