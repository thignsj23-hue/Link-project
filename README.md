# LINK

Assistente Android com conversa de IA opcional e ferramentas locais.

- App e instruções de compilação: [LINK-Android/README.md](LINK-Android/README.md)
- Backend FastAPI: [LINK-Backend/README.md](LINK-Backend/README.md)

Tradução de texto, leitura de texto em imagens e voz local não consomem créditos OpenAI. A conversa inteligente na nuvem depende da configuração e dos créditos do backend.
